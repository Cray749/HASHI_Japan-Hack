# HASHI 橋 / पुल / ਪੁਲ

**Don't translate. Understand.**

A cabin communication layer for flights between India and Japan. Passengers who speak
Hindi or Punjabi tap a picture or speak; the crew tablet shows a card in Japanese with an
English subtitle; the reply returns as picture, audio and large text, and the passenger
taps "understood".

Built for the Thapar Japan Hackathon 2026, problem JAL-PS-02.

_Work in progress. Full documentation arrives with the final milestone._
