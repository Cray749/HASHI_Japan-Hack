# Privacy

HASHI is built to hold as little as possible, for as short a time as possible.

* **No names.** The crew see a seat, a language and the needs the passenger chose. Nothing else identifies a person.
* **Consent first.** The passenger sees, in their own language, what the crew can see and that voice is not saved, and chooses between "OK, I can speak" and "Pictures only" before the microphone is ever requested.
* **Voice is processed in memory.** The phone records, the server cleans and recognises the audio, and both discard it. No audio file is written on the server or kept on the phone.
* **Per-flight data lives in server memory.** It is not written to disk. When the crew press **Landed**, the server wipes every seat, request and announcement and tells every phone to delete its saved profile.
* **No cloud.** The default setup never contacts the internet at runtime. An online speech backup is possible but is off unless explicitly switched on.
* **Crew stay in charge.** HASHI flags urgency. It never diagnoses, never gives medical advice, and every medical-looking request is marked urgent and sent to a human.
* **Local storage on the phone** holds only the language, seat, display preferences and a copy of the request catalogue for offline use. It is removed at landing.

What is not covered yet: a formal data-protection review for an airline, retention rules agreed with a carrier, and an access policy for who may operate a crew tablet.
